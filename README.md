# Globalresearch

글로벌리서치팀 업무개선용

## 시나리오 분석기

애널리스트가 제시한 시나리오에 해당하는 과거 사례를 찾아, 원하는 자산의 이후 수익률과 최대낙폭을 분석하는 프로젝트입니다.

## 현재 상태

기존 구현은 근원 CPI·비농업고용·ISM 제조업의 복합조건을 분석하는 프로토타입입니다. 현재 분석 기준은 [AGENTS.md](AGENTS.md)에 정리되어 있으며, 기존 코드에 모두 반영된 상태는 아닙니다. [CLAUDE.md](CLAUDE.md)는 이전 작업의 참고 기록입니다.

현재 확정된 기준은 다음과 같습니다.

- 컨센서스가 필요한 데이터: Investing.com을 브라우저로 조회합니다.
- 컨센서스가 필요하지 않은 데이터: FRED API를 우선하고, 이후 Investing.com을 사용합니다.
- 경제지표는 발표 당시 값만 사용합니다.
- 모호한 조건과 조건 판정 시점은 사용자에게 확인합니다.
- 수익률은 발표일 종가부터 대상 시장의 거래일 기준으로 계산합니다.
- 표시하는 소수값은 소수점 첫째 자리까지 반올림합니다.
- 매체 코멘트를 인용하지 않고 관측 데이터에 근거한 자체 해석을 작성합니다.

기존 `scripts/prices.py`에는 yfinance 수집 코드가, `scripts/fetch_bls.py`에는 BLS 직접 조회 코드가 남아 있습니다. 새 분석에 사용하기 전에 AGENTS.md의 출처 규칙에 맞게 수정해야 합니다. 기존 보고서 생성 코드와 숫자 표기 역시 최신 명세와의 일치 여부를 확인해야 합니다.

## 주요 파일

| 파일 | 역할 |
|---|---|
| `AGENTS.md` | 현재 프로젝트 작업·분석 규칙 |
| `scripts/parse_investing.py`, `scripts/ingest_tsv.py` | 수집한 경제지표 원문 정제 |
| `scripts/load_events.py` | 이벤트 데이터 구조 검증 |
| `scripts/screen.py` | 기존 복합조건의 사례 선별 |
| `scripts/eventstudy.py`, `scripts/analyze.py` | 수익률·최대낙폭·통계 계산 |
| `scripts/check_anatomy.py` | 해석 문장과 수치 근거 대조 |
| `scripts/figures.py`, `scripts/report.py` | 기존 차트·보고서 생성 |
| `scripts/verify_stack.py` | HTML·PDF 생성 최소 구현 |
| `data/series_map.json` | 기존 지표 식별자 매핑; 새 출처 규칙에 맞춘 검토 필요 |

## Git에 포함하는 범위

코드, 프로젝트 지침, 이 설명서, 기존 지표 매핑을 버전 관리합니다.

`.gitignore`는 다음 파일을 Git 추적 대상에서 제외합니다. 로컬 파일은 삭제하지 않습니다.

- `.env` 등 인증정보 파일
- `data/series_map.json`을 제외한 `data/`의 수집 데이터와 분석 자료
- `_out/`의 생성 보고서·차트·계산 결과
- Python 캐시·가상환경·백업 파일

따라서 저장소를 새로 내려받은 환경에는 분석 입력 데이터가 포함되지 않습니다. 분석하려면 지정 출처에서 필요한 데이터를 확보하고, 출처 및 발표 당시 값 검증을 거쳐 로컬에 준비해야 합니다. API 키를 코드나 커밋에 넣지 않습니다.

## 개발 환경

기존 작업 환경은 Windows와 Python입니다. 환경 관련 기록은 AGENTS.md의 개발 환경 항목에 있습니다. 아직 의존성 잠금 파일과 새 환경에서의 전체 실행 검증은 준비되지 않았습니다.

Git 업로드 준비는 프로젝트 보관·변경 이력 관리를 위한 작업이며, 새 출처 정책 적용이나 범용 시나리오 분석 기능 구현을 의미하지 않습니다.
